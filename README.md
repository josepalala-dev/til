### Additional Developer Tools

Useful tools for navigating projects, searching files, and working efficiently in the terminal.

- [zoxide](https://github.com/ajeetdsouza/zoxide) — jump between frequently used directories.
- [fzf](https://github.com/junegunn/fzf) — interactively search files, command history, and other lists.
- [ripgrep (`rg`)](https://github.com/BurntSushi/ripgrep) — search file contents quickly.
- [fd](https://github.com/sharkdp/fd) — find files and directories with simpler syntax.

`fd` and `ripgrep` cover many common `find` and `grep` use cases, but they are not exact replacements.
